# Dear Letter v0.2 — Draft Library & Recipient Envelope

Status: local MVP implementation. Release NOT approved.

- Save, reopen, edit, and delete up to 12 opt-in local drafts; stored in plaintext browser localStorage.
- V0.1 draft migration when explicitly re-saving.
- CSS envelope-opening animation with reduced-motion behavior.
- Node automated tests for drafts, crypto, static server; constrained Chromium DOM smoke.
- Real HTTP + WebCrypto E2E blocked in runner by browser administrative policy; run on local workstation before merge.

Shared links include encryption key in URL fragment, so anyone with the full URL can read them. There is no account, server storage, revocation, or commercial launch authorization.
