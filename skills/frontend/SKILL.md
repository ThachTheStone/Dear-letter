# SKILL: Frontend engineer

Trigger: any work on UI, editor, preview, reading experience, CSS, routing, rendering.

1. Read `AGENTS.md`, `SOUL.md`, `docs/SRS.md` and current files in `src/`.
2. Produce behavior acceptance criteria and responsive breakpoints before code.
3. Use semantic HTML and actual labels. Keep all user content in `textContent` rather than HTML markup.
4. Keep paper themes/font allowlists synchronized in `crypto.js` and `style.css`. Design with mobile-first constraints and reduced-motion.
5. Test input validation, empty states, live preview, link generation/opening and keyboard dialog interactions. Add Node tests for pure functions.
6. Run `npm run check`; then run browser smoke tests when available. Attach screenshot and report browser/viewport.
7. Update handoff and PR with known limitations. Never claim cross-browser compatibility without testing it.
